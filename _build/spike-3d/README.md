# 3D spike (scratch)

A throwaway test page that answers one question: should Payton Pizza be drawn in 3D?
It is not part of the game. Pass/fail lines are in `PASS-LINES.md`, written before the page was built.

- Published at https://trureveal-ai.github.io/payton-pizza/spike-3d/ by `.github/workflows/spike-3d.yml` (this branch only).
- Run locally: `npm install`, then `npm run dev`.
- Everything is built in code with Three.js: no image or model files.
- Keys: arrows steer, Z / X throw left / right, Space throws at the nearest order, C changes camera.

When the test is over, delete the `spike-3d` branch and the `spike-3d/` folder on `gh-pages`.
