# v0.1.0 — Repo and walking skeleton

Payton Pizza now lives in this repo and publishes itself to a beta address. The game plays exactly as the prototype did.

## What's new

- Beta copy at https://trureveal-ai.github.io/payton-pizza/beta/, republished on every merge to `main`.
- "Coming soon" stays at the live address until v1.0.0.
- A page icon.

## What's better under the hood

- The single-file prototype is split into eleven modules, built with Vite.
- Lint, 14 unit tests and browser tests at desktop and phone sizes run on every pull request.
- Releases are automatic: changing `VERSION` on `main` tags and publishes.

## Tested

- Nine recorded runs (three input scripts, three seeds) replayed against the prototype with a seeded random source and a fixed time step: every run ends on an identical frame.
- 14 unit tests; 5 browser tests (title, start and play at desktop and phone sizes, garage).

## Known limits

- Not yet checked on a real phone from the beta address.
- The black car is still named Midnight Coupe until v0.2.0.
- Streets are random on every run until v0.2.0.
